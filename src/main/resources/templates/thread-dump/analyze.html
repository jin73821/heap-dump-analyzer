스레드 덤프 파일로 내보내기

        

            
이 힙 덤프의 스레드를 jstack 형식 텍스트 파일로 저장하고, 스레드 덤프로 분석까지 마쳐 스레드 덤프 목록에 올립니다.

            
            
    
                
  • 파일 이름은 <힙 덤프 이름>_threads.txt 입니다. 같은 이름이 있으면 덮어쓰지 않고 물어봅니다.
    • 
                
  • 내보낸 파일은 이 힙 덤프와 연결된 상태로 등록됩니다 — 스레드 표에 힙 점유가 붙습니다.
    • 
                
  • 내보낸 뒤 바로 분석하므로 목록에 '완료' 로 올라갑니다. 힙 덤프에 없는 정보(CPU·락 관계·스냅샷 비교)는 파일에도 없습니다.
    • 
            

            

        

        

            
            
            
            
            
        

    






    

        
AI 분석 시작

        

            
LLM 이 소견·교착 사슬·락 경합·정체 스레드의 스택을 종합해 근본 원인과 조치를 제시합니다.

            
            
    
                
  • 외부 LLM API 를 호출하므로 API 비용이 발생할 수 있습니다.
    • 
                
  • 분석 요약과 스택의 클래스·메서드 이름이 LLM 으로 전송됩니다. 덤프 원문 전체는 보내지 않습니다.
    • 
                
  • 모델에 따라 15~40초 정도 걸립니다.
    • 
                
  • 기존 AI 분석 결과가 새 결과로 대체됩니다.
    •
