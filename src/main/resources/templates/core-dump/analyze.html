📚 라이브러리 번들 (sysroot)

        
        

            원본 서버의 공유 라이브러리(.so)를 담은 번들입니다. 번들이 있으면 재분석 시
            GDB 가 분석 서버 로컬 라이브러리 대신 번들을 사용해 원본 서버와 동일한 심볼 정확도를 냅니다.
            (버전이 다른 라이브러리는 경고 없이 잘못된 함수명을 만들 수 있습니다.)
        

        
상태 확인 중…

        

        

            
            
            
        

        

            압축 번들(tar · tar.gz · tgz · tar.bz2 · tar.xz · zip)과
            개별 라이브러리 파일(.so 등)을 모두 올릴 수 있고,
            여러 개를 한 번에 선택해도 됩니다. 형식은 확장자가 아니라 파일 내용으로 판별합니다.
            업로드분은 기존 번들에 추가되며(같은 경로는 덮어씀), 처음부터 다시 구성하려면
            '번들 삭제' 후 올리세요. 원본 경로를 모르는 개별 파일도 파일명으로 탐색됩니다.
